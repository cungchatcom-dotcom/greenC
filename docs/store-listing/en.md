## App Name
GreenC

## Short Description (up to ~100 characters)
Monitor drive C: usage, clean temporary clutter into a 7-day Safety Vault, and keep your disk healthy.

## Description
GreenC is a lightweight, 100% local disk-space management utility for Windows that helps you see what is filling up drive C: and reclaim space safely without risking accidental data loss.

Key capabilities:
• Overview & Space Lens: Track drive C: free space, daily growth trends, estimated days remaining, and inspect folders visually with the interactive Space Lens treemap.
• Safe Cleanup with Canary Safety Vault: Before removing temporary files or application caches (browsers, chat caches, Windows temp, developer package caches), GreenC checks for locked files using Windows Restart Manager and archives items into a local ZIP64 Safety Vault (7-day default retention) so you can restore individual files or an entire cleanup.
• Per-Drive Quotas & Low-Memory Tray Mode: Configure capacity thresholds per drive and minimize GreenC to the system tray for quiet background monitoring.
• In-Place NTFS Compaction (WOF) & Safe Relocation: Compress cold folders transparently with Windows WOF CompactOS and relocate supported non-AppData developer tool directories to a secondary NTFS drive with undo support.
• Local-Only & Private: All scanning, archiving, and cleanup happen locally on your PC. No accounts, no ads, no analytics, and no personal file uploads. The Microsoft Store edition is updated exclusively through Microsoft Store and makes no outbound network requests of its own.
• Instant Language & Theme Switching: Built-in English, Vietnamese, and additional locales with Light, Dark, and System theme modes.

System Requirements:
• Windows 10 version 1903 (build 18362) or later, or Windows 11 (64-bit: x64 and native Arm64).
• Requires Microsoft Edge WebView2 Runtime (pre-installed on Windows 11 and updated Windows 10 systems).

## App Features (Partner Center bullet points)
- Real-time drive C: usage overview, daily growth tracking, and fullness forecast

- Configurable per-drive quotas, rolling rules, and low-memory system tray mode

- 100% local processing with no ads, no telemetry, and no cloud uploads
